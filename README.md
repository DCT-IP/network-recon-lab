# Network Recon Lab

A hands-on cybersecurity and networking repository focused on learning:

- Packet analysis
- Network reconnaissance
- Protocol behavior
- Python socket programming
- Network scanning
- API and web security fundamentals

This repository follows a practical engineering-first approach:
understanding how systems work before attempting to secure or attack them.

---

# Objectives

This project is designed to build strong foundations in:

- Computer networking
- Cybersecurity fundamentals
- Traffic analysis
- Enumeration and reconnaissance
- Python networking
- Backend/API security awareness
