# Network Recon Lab

A hands-on cybersecurity, networking, and systems repository focused on learning:

- Packet analysis
- Network reconnaissance
- Protocol behavior
- Python socket programming
- Network scanning
- Web security fundamentals
- API security
- Linux and shell fundamentals
- Security automation

This repository follows a practical engineering-first approach:
understanding how systems work before attempting to secure or attack them.

---

# Objectives

This project is designed to build strong foundations in:

- Computer networking
- Cybersecurity fundamentals
- Linux environments
- Traffic analysis
- Enumeration and reconnaissance
- Python networking
- Backend/API security awareness
- Security tooling and automation
